### Пакеты, которые не удалось запустить

Не все G2P-библиотеки удалось протестировать из-за ограничений окружения (Windows, Python 3.14) или отсутствия системных зависимостей.

| Пакет | Статус | Причина сбоя |
|---|---|---|
| `epitran` | Не установился | Зависимость `editdistance` требует компилятора Microsoft C++ Build Tools (нет готового wheel для Windows). |
| `transphone` | Не установился | Та же проблема с `editdistance`. |
| `kokorog2p` | Упал при запуске | Требует установленный системный движок `espeak-ng` (переменная `ESPEAKNG_RUNTIME_EXECUTABLE`). |

**Вывод:** В отличие от этих пакетов, `crispy-ipa` устанавливается одной командой `pip install` на любой чистой системе без необходимости компиляции C++ кода или установки внешних бинарников.
