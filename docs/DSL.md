# Синтаксис DSL и пайплайн обработки правил (`crispy_ipa`)

## 1. Синтаксис правил

Каждое правило записывается с новой строки в одном из двух форматов:

* **Безусловный переход:** `L -> R`
* **Контекстный переход:** `L -> R / C`

Где:
* **`L`** — исходная графема, фонема или шаблон для замены.
* **`R`** — целевая строка (результат замены).
* **`C`** — фонетическое или орфографическое окружение, где символ **`_`** обозначает позицию заменяемого элемента `L`.

Пустые строки и строки, начинающиеся с `#`, игнорируются как комментарии.

### Специальные символы
* **Граница слова (`#`):** перед применением правил каждое слово в тексте автоматически обрамляется символами `#` (например, `#word#`), а после выполнения правил символы `#` удаляются. Это позволяет использовать `#` в контексте как обычный символ:
  * `#_` — начало слова (`kn -> n / #_`)
  * `_#` — конец слова (`e -> ∅ / _#`)
  * `_!#` — не в конце слова
* **Удаление звука (`∅`, `_`):** если в правой части `R` указан один из этих символов, он заменяется на пустую строку `""` (`h -> _ / [V]_#`).

### Макросы
Макросы задаются в словаре `macros: dict[str, str]` и подставляются в текст правил **до** их парсинга (в порядке убывания длины ключа, чтобы длинные имена не перекрывались короткими).

```python
macros = {
    "[V]": "[aeiouy]",
    "[C]": "[bcdfghklmnpqrstvwxz]",
    "[Z']": "(b|d|g|v|z|ð|ʒ|m|n|ŋ|l|r|w|ɹ)",
}
```

### Группы, классы символов и квантификаторы
В частях `L`, `R` и `C` поддерживаются два вида группировок:
1. **Символьный класс `[abc]`** — разворачивается в посимвольные варианты `('a', 'b', 'c')`.
2. **Альтернативы `(a|b|c)`** — разворачиваются в многосимвольные варианты `('a', 'b', 'c')`.

В левой части `L` дополнительно поддерживаются квантификаторы:
* **Необязательный элемент (`?`):** `t?ch -> tʃ` разворачивается в `tch -> tʃ` и `ch -> tʃ` (длинный вариант идёт первым).
* **Повторение (`{n}`):** `[C]{2} -> [C]` разворачивается в идентичные повторы (`pp -> p`, `tt -> t`, `kk -> k` и т.д.).

### Сопоставление `L` и `R`
* **Один ко многим (`[sz] -> ʃ`)**: если в `R` один вариант, он применяется ко всем вариантам `L`.
* **Один к одному (`[aeiouy] -> (ɑː|ɜː|ɜː|ɔː|ɜː|ɜː)`)**: варианты `L` и `R` сопоставляются попарно по индексу (`a -> ɑː`, `e -> ɜː` и т.д.).

### Контекст `C` и отрицания `!`
* **Позитивный контекст:**
  * `_C` — перед `C` (`k -> s / _[ei]`)
  * `C_` — после `C` (`s -> z / [Z']_#`)
  * `C1_C2` — между `C1` и `C2` (`t -> ɾ / V_V`)
* **Отрицание `!`:** ставится перед одиночным символом (`!r`), классом (`![V]`) или группой (`!(th|sh)`). Означает, что на этой позиции **не должно** быть указанных символов.
* **Составной контекст:** допускаются любые комбинации, например `_r![V]` («после `L` идёт `r`, а сразу за ним — не гласная»).

## 2. Пайплайн компиляции и выполнения

Пайплайн разделён на два независимых этапа: вся комбинаторная разворачиваемость и компиляция контекстов выполняются один раз при сборке пакета, а в рантайме работают только готовые кортежи без парсинга и регулярок.

```text
[data_src/eng_to_ipa_rules.py]  (сырые rules + macros)
              │
              ▼  1. expand_macros()
   Подстановка макросов по убыванию длины ключа
              │
              ▼  2. parse_lines()
   Разбор строк регуляркой в тройки (L, R, C)
              │
              ▼  3. expand_optionals() -> expand_repeats() -> expand_pair()
   • Раскрытие ?, {n}, [...] и попарное сопоставление L и R
   • Нормализация символов удаления (∅, 0, _) в ""
              │
              ▼  4. expand_context() -> compile_context()
   • Комбинаторное раскрытие позитивных групп в C
   • Компиляция левой и правой частей от '_' в шаги (is_negated, variants)
              │
              ▼  5. compile_dsl_rules() -> pickle
[src/crispy_ipa/data/eng_to_ipa_rules.pkl]  (список (L, R, left_steps, right_steps))
              │
              ▼  6. apply_rules() + unicodedata.normalize('NFC')
   Обрамление слов в '#', последовательное применение правил, снятие '#'
```

### Пример трансформации правила

**Исходник:**
```python
macros = {"[V]": "[aeiouy]"}
rules = "[aeiouy] -> (ɑː|ɜː|ɜː|ɔː|ɜː|ɜː) / _r![V]"
```
